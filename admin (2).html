How do I get a token?
  1. Log in to GitHub, then open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens.
  2. Tap Generate new token. Give it any name and set Expiration to the longest you can.
  3. Under Repository access choose “Only select repositories” and pick H-A-house.
  4. Under Permissions, open Repository permissions and set Contents to Read and write.
  5. Generate the token, copy it and paste it above.
